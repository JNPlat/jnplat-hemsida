# JNPlåt – hemsida

Hemsida för J. Norberg Plåtslageri AB.

## Struktur

- `index.html` – startsida
- `style.css` – design och responsiv layout
- `script.js` – mobilmeny
- `logo/J.NORBERG.svg` – företagets officiella logotyp
- `images/` – projektbilder läggs här

## Nästa steg

1. Byt ut bildplatshållarna mot riktiga projektbilder.
2. Lägg till telefonnummer och eventuella företagsuppgifter.
3. Bygg undersidor vid behov.
4. Koppla GitHub-repot till Cloudflare Pages.
5. Koppla `jnplat.se`.
